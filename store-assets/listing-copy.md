# Chrome Web Store Listing Copy

## Name

Adyen Web Inspector

## Summary (<= 132 chars)

Inspect Adyen Web integrations for configuration issues, risky patterns, and clear remediation steps.

## Description

Adyen Web Inspector is an independent Chrome extension for reviewing Adyen Web Drop-in and Components integrations. Open it on a checkout page and run a scan to see the integration’s health score and what needs attention.

- Start in the popup for a quick summary, or choose the Detailed view for remediation and implementation attributes.
- Investigate further in Chrome DevTools, with separate views for best practices, security, skipped checks, captured requests, and extracted checkout configuration.
- Open the full report to see what to fix first and filter findings by severity. Export JSON or save a printable PDF for sharing.
- Choose light, dark, or system appearance.

The inspector observes browser-side checkout signals. Server-side logic and payment API request bodies are outside the scan’s scope. This is an independent developer tool with no official Adyen affiliation.
